# Vcttmvmam_Bzivatibwz-I (Nullenese Translator)

Nullenese Translator for the soldiers of Null on the Unstable SMP, written with Java.

## what is Nullenese?

Nullenese is the language of Null, the oldest army on the Unstable SMP

## Compiling

`javac Main.java`

### Sidenote:

Because the program relies on English characters (a-z) the use of Non-English characters will not necessarily break the program, but will lead to miscellaneous outputs.
